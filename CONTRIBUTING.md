## Prerequisites

[Node.js](https://nodejs.org/) 24 and pnpm 11 must be installed for development.

## Installation

- Running `pnpm install` in the component's root directory will install everything you need for development.

## Demo Development Server

- `pnpm dev` will run a development server with the component's demo app.

## Running Tests

- `pnpm test` will run the tests once.

- `pnpm test:watch` will run the tests in watch mode.

- `pnpm typecheck` will check the TypeScript source without emitting files.

- `pnpm lint` will lint the source and demo app.

## Building

- `pnpm build` will build the component for publishing.

- `pnpm clean` will delete built resources.
